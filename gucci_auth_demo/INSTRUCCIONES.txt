REQUISITOS
──────────
- Python 3.10 o superior
- Librería `requests` (viene incluida en Python estándar)
- API Key de Google Gemini (gratis en: https://aistudio.google.com/apikey)


ESTRUCTURA DE CARPETAS
──────────────────────
gucci_auth_demo/
├── main.py          ← script principal
├── criteria.py      ← criterios de autenticación Gucci
├── analyzer.py      ← motor de análisis con Gemini Vision
├── report.py        ← formato del reporte
└── INSTRUCCIONES.txt


CÓMO USAR
─────────
1. Obtener una API Key de Gemini:
   Ir a https://aistudio.google.com/apikey y crear una key gratuita.

2. Preparar las fotos del producto en una carpeta.
   Nombrarlas así (soporta .jpg, .jpeg, .png, .webp):

   01_gg_canvas.jpg    → Patrón GG Canvas (frente del producto)
   02_herrajes.jpg     → Herrajes / cierres / argollas (close-up)
   03_etiqueta.jpg     → Etiqueta interior con número serial
   04_costuras.jpg     → Detalle de costuras (lateral)
   05_interior.jpg     → Interior / forro del producto
   06_cierre.jpg       → Sistema de cierre / solapa principal
   07_challenge.jpg    → Foto con código de sesión (anti-fraude)

   No es necesario tener todas las fotos. Las que falten se excluyen
   del cálculo y el score se pondera sobre los criterios disponibles.

3. Ejecutar el script:

   python main.py --api-key TU_API_KEY --folder ./ruta/a/las/fotos

   Ejemplo:
   python main.py --api-key AIzaSy... --folder ./fotos_bolso_gucci

NOTAS
─────
- El análisis tarda ~5-10 segundos por foto (depende de la conexión).
- La API de Gemini tiene un tier gratuito generoso (1500 req/día).
- Los prompts están calibrados para Gucci leather goods y GG Canvas.
  Otras categorías (calzado, ropa) pueden requerir ajustes en criteria.py.
